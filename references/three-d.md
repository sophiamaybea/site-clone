# 3D capture and generation

Save public .glb, .gltf, .obj, .fbx, .usdz, .hdr, and splat files. Leave Sketchfab and Spline embeds remote.

If the page is only a canvas, run scripts/generate_standin.py. That writes an original glTF, a Blender script, and scene/viewer.html. Do not copy a trademarked mesh.
